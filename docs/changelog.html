Version: v3.2.12 ← Back to Documentation

[Unreleased] — Custom Class Color Support for Ascension

  • [Feature — Ascension Class Colors] Added support for all 32 class tokens used by Conquest of Azeroth and other Ascension private servers. Class colors are now dynamically loaded from RAID_CLASS_COLORS at runtime, making all custom classes available in the options panel.
  • [Fix — Class Color Options Display] Fixed the class color options UI to properly display all available classes instead of only standard WoW classes. On Ascension realms, all 32 classes now appear in the color configuration panel.
  • [Fix — Nil Color Fallback] Added defensive handling in color get/set functions to prevent crashes when accessing colors for classes not in the defaults table. Unknown classes now safely fall back to a default color.
  • [Fix — PET and VEHICLE Colors] Ensured PET and VEHICLE pseudo-classes remain visible and configurable on all server types.
