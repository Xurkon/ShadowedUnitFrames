Shadowed Unit Frames

A lightweight, highly configurable unit frame addon for World of Warcraft.

Version: v3.2.12 View Changelog

Overview

Shadowed Unit Frames (SUF) is a comprehensive unit frame addon that provides fully customizable frames for Player, Target, Party, Raid, and more. It supports custom class colors, tags, auras, and includes features like heal predictions, portraints, and combat text.

Custom Class Colors

SUF supports custom class colors for both standard and custom server classes. Class colors are configurable through the options panel under General -> Colors -> Class Colors.

Standard Classes

All standard WoW classes are supported: Warrior, Paladin, Hunter, Rogue, Priest, Death Knight, Shaman, Mage, Warlock, and Druid.

Custom Server Classes

Private servers with custom class systems (such as Ascension) can add their own class tokens for coloring.

Ascension Support: When running on Conquest of Azeroth or other Ascension realms, all 32 class tokens are automatically detected and made available in the class color options.

Configuration

All configuration is done through the Shadowed UF Options panel, accessible via the Blizzard options menu or typing /suf in chat.

Key Options

  • General - Frame layout, sizing, and global settings
  • Units - Configure individual unit frames (Player, Target, Party, Raid, etc.)
  • Tags - Custom text tags using the tag system
  • Auras - Buff and debuff display settings
  • Colors - Class colors, health colors, power colors

Tag System

SUF includes a powerful tag system that allows you to display dynamic information on unit frames.

Available Tags

[name] - Unit name
[level] - Unit level
[class] - Class name
[health] - Current health
[health:percent] - Health percentage
[power] - Current power
[power:percent] - Power percentage
[status] - Dead/Offline/AFK status
[guild] - Guild name (if available)

Custom Tags

You can create custom tags in the Tags section of the options panel. Tags can include Lua code for advanced formatting.

Modules

SUF is organized into modular components:

Health

Health bar coloring and display, including class colors, health predictions, and absorbs.

Power

Power bar display for mana, rage, energy, and other power types.

Auras

Buff and debuff tracking with filtering, sorting, and highlighting options.

Portrait

3D and 2D character portraits on unit frames.
